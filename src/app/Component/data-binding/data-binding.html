Two way

From .ts to HTML
  • Interpolation

    • Used to display data in HTML
    ✔ Displays values from the component in the UI
    ✔ Read‑only (you can’t update TS from HTML)

  • Property Binding

    • Used to bind HTML element properties.
    Binds TS data to HTML element properties (src, disabled, value, etc.)

From HTML to .ts
  • Event Binding

    • Used for capturing user actions like clicks, keypress, etc.
    Used to capture HTML events and call a method in TypeScript. ✔ HTML event triggers a method in TS
    ✔ UI updates automatically

NGModel

Used when you want changes in the UI to reflect in TS and vice‑versa.
Requires FormsModule.

  • Used for two‑way update: HTML ↔ TS.
  • Works ONLY with ngModel.
